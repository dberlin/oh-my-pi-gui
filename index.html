omp GUI

A desktop GUI for the omp coding agent. Every slash command as a menu, full-fidelity rendering, and true multi-window parallel sessions — no separate install required.

Download for macOS View on GitHub

Built for how you actually work

The agent runs as a bundled sidecar over a typed NDJSON RPC bridge — fast, isolated, self-contained.

◆Parallel sessions

Up to 10 windows, each with its own independent agent sidecar. Switch or create sessions in one window without ever disturbing a session running in another.

◆Every command, as a menu

Slash commands become grouped, searchable menus. Open the Command Palette (⌘K) for fuzzy access to everything — sub-menus, argument prompts, and toggles all run the real RPC.

◆Full-fidelity rendering

Streaming text, collapsible thinking blocks, live tool cards with real diffs, markdown, KaTeX math, mermaid diagrams, and syntax-highlighted code — token by token.

◆Providers & login

Sign in with OAuth or API keys, add third-party providers, edit models.json, and see auth status at a glance.

◆Usage & quotas

A full stats dashboard — requests, tokens, cost, cache-hit, speed, errors, per-agent breakdown — with time ranges and charts.

◆Workspace panels

Todo, Plan, Subagents, Diff, Files, and Logs in a collapsible side panel, kept in sync with the agent in real time.
