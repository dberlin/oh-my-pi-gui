Install

两种装法,都只要一分钟。

下载即用(推荐)

macOS 13+,Apple Silicon 或 Intel。拖入 /Applications 即可——agent、运行时、原生插件全部内置。

Apple Silicon 150 MB Intel 166 MB
未签名构建:首次打开如被 Gatekeeper 拦截,右键 → 打开,或执行 xattr -dr com.apple.quarantine /Applications/omp.app。签名与公证在路上。

从源码构建

# 1. monorepo(fork,含 GUI 使能改动)
git clone https://github.com/nornzach/oh-my-pi.git omp-monorepo
cd omp-monorepo && bun install && cd ..

# 2. GUI 仓库,嵌套到 packages/gui
cd omp-monorepo/packages
git clone https://github.com/nornzach/oh-my-pi-gui.git gui
cd gui && bun install

# 3. 编译 sidecar 并打包
bun run build:omp
bun run package:mac:arm64
