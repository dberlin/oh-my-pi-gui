## 1. Dialog framework and animations

- **All Modal dialogs** — `src/renderer/components/common/Modal.tsx: Modal`, `hooks/use-overlay-presence.ts: useOverlayPresence`, `styles/global.css:.omp-fade-out/.omp-scale-out`. Before, callers could clear payload during close and collapse the exiting panel, and the old exit class wiring often snapped away. After, the last open title/body is retained, the closing overlay is inert, and backdrop/panel animate out for **150 ms** (fade plus scale to 0.96/translateY 6 px); reduced-motion skips the exit. Open and close any dialog with button, Escape, and backdrop to expose.
- **Command Palette** independently gains `omp-fade-in`; **ContextMenu** gains `omp-pop-in`. Disabled Button/Tabs/context-menu rows become less faded (opacity 0.70 vs 0.50/0.40/0.45), so capture a menu/dialog containing unavailable actions.
- **AsyncSection** — new `components/common/AsyncSection.tsx`. Before, affected panes used plain spinner/error text/empty text. After, initial error has amber AlertTriangle, optional heading, and Retry; empty has Inbox; stale data stays visible under a warning banner with Retry. Used by Active Tools, Session Info, Workspace Directories and settings/panel surfaces.
- **ConfirmDialog** — new `components/common/ConfirmDialog.tsx: ConfirmDialog`: compact destructive modal with muted message, amber consequence line, safe Cancel autofocus, danger confirm. Used here for sidebar deletes and Full access; settings-only uses are flagged below.

## 6. Native windows, dialogs, tray, preload

- **App quit guard** (`main/app-quit.ts: installQuitGuard`; `preload/index.ts: omp.app.quit`): idle tabs quit silently. With any stream/compaction, ⌘Q, native Quit, or `/quit` opens native warning:
  - Title **Sessions are still running**
  - Detail **“{working} of {total} sessions are still working in {windows} window(s). Quitting stops them and their agents.”**
  - Buttons **Quit anyway** / **Keep working**, safe button default/cancel. Repeated ⌘Q does not stack dialogs.
- **Resources-changed recovery** (`main/window.ts:#confirmRestartForChangedResources`): before, eligible renderer failure automatically relaunched/killed live agents. After, one native question per run: **Restart to finish updating**; body says installed files changed and gives working/total count; buttons **Restart now** / **Later**. Console errors and navigation no longer trigger relaunch; only main-frame load failure or reloadable process death.
- **Window restore** (`main/window.ts`, `window-bounds.ts`, `index.ts`): all saved windows/layouts restore, not only primary; closing a secondary removes it from next launch; off-screen windows recenter/fit within primary work area; Windows auto-hides native menu bar. Explicit OS path opens/focuses that workspace; bare New Window uses GUI-owned/last usable workspace rather than Finder `/`. Capture restart with two windows and unplugged-display geometry if board needs behavioral proof rather than a static frame.
- **Deep link/open-file** (`main/deep-link.ts`): startup URLs/files are queued until setup; second-instance absolute workspace paths now focus an existing window or spawn one instead of no-op.
- **Tray** (`main/tray.ts`, `tray-labels.ts`): header changes from **“● omp — project”** to **“omp — project · Idle/Running/Needs input/Error”** (localized); same state appears in hover tooltip. Context with tokens but unknown capacity now displays **Context: — · N tokens** instead of omitting usage. Status aggregates all windows with error > running > waiting > idle; Show/Hide targets focused window. Static π icon itself does not visually change. Menu no longer disappears while open due background updates.
- **Sidecar crash loop** (`main/sidecar.ts`, `hooks/use-rpc-events.ts`, `stores/ui.ts`, `layout/SidecarBanner.tsx`): before only final red failure; after each respawn shows amber banner with spinning Refresh icon, **Agent restarting**, **Restart attempt {attempt}/{maxAttempts} — {reason}**; exhaustion returns red **Gave up after {maxAttempts} restart attempts** and includes first stderr line in reason. Dismiss now hides this diagnostic until a new diagnostic/recovery rather than clearing underlying state. Packaged missing binary copy changes from developer build instruction to **“omp is missing from this installation (…). Reinstall omp GUI, then relaunch.”**
- **Stats start state** (`main/ipc.ts`, `hooks/use-stats.ts`): dashboard remains in loading/ **“Stats server is starting and syncing history…”** while retrying every 2 s for up to 90 s, then shows terminal error; wrong-shaped list response is error, not empty rows. This is a stats-surface capture, not a new dialog.
- **Updater**: interrupted macOS transfer resumes from `.partial`, so update progress may reopen above zero. Renderer updater store persists dismissed-version and dismissed-error across relaunch; successful update status re-arms a dismissed error. New UpdateBanner close tooltip is **Dismiss this update notice**. No new native dialog.
- **Preload subscribe guard** is internal except it prevents one broken IPC listener from freezing later visible updates; preload’s only direct new affordance is app-wide guarded quit.

## 7. State-driven visible changes from hooks/stores

- Context usage refreshes on heartbeat/idle snapshots and model switches; the gauge/cost no longer freezes between transcript appends or retains the prior model window.
- Model/provider catalog commits are generation-guarded, preventing stale provider/model rows after a push/read race; reselecting current model repairs stale label from response.
- Session-list, subagent-roster, and active-resource failures are no longer false empty states. Subagent panels show **Could not load the subagent roster** while preserving stale rows (owning panel, not duplicated here).
- Unanswered historical tool calls now render terminal **Interrupted** rather than spinning forever; only unanswered calls in the currently live trailing turn remain running (`stores/tools.ts: hydrateMessages`).
- Streaming text keeps six reveal frontiers so already shown text does not restart/flicker its fade. This is transcript-only presentation and is flagged for the transcript owner rather than duplicated as an approval tile.
- New session-store pin nonce snaps transcript to live edge after submit; transcript-specific layout is likewise delegated.
